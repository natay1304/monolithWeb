# assets/cases — медиа для карточек 04 // РАБОТЫ (кейсы)

Сюда кладутся реальные изображения и видео для карточек страницы 04 (`#/capabilities`). Услуги с ценами живут отдельно — массив `SERVICES` в `content.js`, страница 03 (`#/services`).

## Как подключить медиа к карточке

В `content.js`, в массиве `ARCHIVE_ITEMS`, у нужного элемента поменяйте поле `media`:

```js
// было (процедурная заглушка в стиле сетки):
media: { type: 'placeholder', src: '' }

// изображение:
media: { type: 'image', src: 'assets/cases/nordkap-01.jpg' }

// видео (проигрывается без звука, зациклено):
media: { type: 'video', src: 'assets/cases/nordkap-loop.mp4' }
```

Больше ничего менять не нужно — рендерер карточек поддерживает все три типа.

## Как добавить первый реальный кейс

Допишите в `ARCHIVE_ITEMS` объект с `kind: 'case'` (шаблон-комментарий лежит в конце
массива в `content.js`). Карточка появится на странице работ автоматически, а у услуг из `SERVICES`, которые перечисляют этот кейс в `cases: [...]`, вместо плашки «демо в подготовке» появится ссылка на него. Движок (`app.js`) не трогается.

## Рекомендации к файлам

- Изображения: JPG/WebP, 1600×900 (16:9), до ~400 КБ.
- Видео: MP4 (H.264), 1280×720, 5–15 сек, без звука, до ~4 МБ.
- Имена файлов: латиницей, через дефис: `case-id-01.jpg`.
