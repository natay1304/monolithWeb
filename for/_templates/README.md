# Шаблоны коммерческого предложения MONOLITH

Три самостоятельных шаблона для точечного КП одной компании. Чистые HTML/CSS/JS, без сборки и внешних JS-библиотек, шрифты только с Google Fonts. Контент у всех трёх лежит в одном объекте `window.OFFER` (RU + EN) с одинаковой схемой: файл `offer.js` можно перенести из одного шаблона в другой.

```
_templates/
  _lib/base.css      общая база: токены, шапка, кнопки ≥44 px, липкий CTA, заглушки, анимации, prefers-reduced-motion
  _lib/kit.js        движок: RU/EN, тема, появление по скроллу, слова/буквы, счётчики, прогресс, параллакс, липкий CTA
  editorial/         index.html · offer.js · render.js · style.css
  index/             index.html · offer.js · render.js · style.css
  halftone/          index.html · offer.js · render.js · style.css
```

## Какой шаблон выбрать

| Шаблон | Образ | Когда брать | Что нужно от клиента |
|---|---|---|---|
| `editorial` | гигантский строчный гротеск, текст поверх кадра, номера и вертикальные подписи на полях, список-навигация со стрелками | Технически амбициозные и «молодые» бренды: станки, электроника, оборудование, дизайн-ориентированный ритейл. КП должно выглядеть как заявление | Один сильный кадр изделия (светлый фон, он станет дуотоном в цвет акцента) |
| `index` | швейцарская сетка, нумерованное оглавление «(1) Задача (2) Что сделаем…», пунктирные плашки под ассеты | Консервативные и инженерные компании, тендерные отделы, длинные цепочки согласования: оглавление помогает пройти по КП с закупщиком. Лучший выбор, если рендеров ещё нет и нужны заглушки | Ничего обязательно: все кадры могут быть заглушками |
| `halftone` | тёплый дуотон-полутон поверх фото компании, карточки изделий, радиальная схема «что получите» вокруг изделия | Потребительские и пищевые товары, ритейл, упаковка, всё где есть «товар на полке» и каталог серий | Фото 3 изделий из каталога (светлый фон) и фото для обложки |

Если сомневаетесь: промышленный производитель с каталогом задвижек, насосов, кабеля — `index`; бренд с характером — `editorial`; товар на полке — `halftone`.

## Как собрать КП под компанию

1. Скопировать папку шаблона в `for/<slug>-<4 hex>/` (slug — латиницей, суффикс затрудняет подбор адреса).
2. Поправить пути (шаблон лежит на уровень глубже, чем готовое КП):
   ```
   cd for/<slug>-<hex>
   sed -i '' 's#\.\./_lib/#../_templates/_lib/#' index.html
   sed -i '' 's#\.\./\.\./_shared/#../_shared/#g' offer.js
   ```
3. Заполнить `offer.js` (см. ниже), поставить `demo:false`, в `contact.brief` прописать ссылку с `src=<slug>`.
4. Тему задать в `theme` (в CSS-переменные превращается автоматически: `accentL` → `--accent-l`).
5. Проверить на 390 и 360 px, затем отправить ссылку (в `<head>` уже стоит `noindex,nofollow`).

## Как заполнить `offer.js`

Любая строка — `{ru:'…',en:'…'}` (допустима и простая строка). Ключи:

| Ключ | Содержимое |
|---|---|
| `demo` | `true` показывает плашку «демо-шаблон». Перед отправкой `false` |
| `name`, `title`, `slug`, `lang` | имя компании, заголовок вкладки, язык по умолчанию (`?lang=en` в ссылке переключает) |
| `contact.brief` | ссылка кнопок CTA |
| `theme` | `accent`, `onAccent`, `bg`, `bg2`, `fg`, `muted`, `line`, `dark`, `onDark`, `onDarkMuted`, `slot` (цвет плашек-заглушек); у `halftone` ещё `duoLight`, `duoDark`. Белый текст на акценте ≥ 4.5:1, акцент как текст только крупным кеглем |
| `blocks` | порядок и состав блоков: `cover, seen, task, make, demo, steps, pricing, assure, more, next` (`index` ещё `toc`, `halftone` ещё `products`) |
| `cover` | `kicker`, `big` (гигант, только editorial), `headline` (одна главная выгода, без слова «ИИ»), `benefit`, `meta[]`, `vert`, `cta`, `img` (фото компании или пусто) |
| `seen.facts[]` | ровно 3: `n`, `count`, `pre`/`suf` (для счётчика), `label`, `src` (источник и дата) |
| `task` | `quote` (задача их словами), `who` (откуда формулировка), `points[]` |
| `make.items[]` | `t`, `fmt` (формат и параметры: PNG 4000 px, GLB до 8 МБ), `d` |
| `demo` | `slots[]` (`t`, `ratio`, `src`: есть `src` — картинка, нет — пунктирная заглушка), `caption` («Демонстрация на условной модели…») |
| `steps` | `items[]` (`d`, `t`, `p`), `note` («сроки от получения исходников») |
| `pricing.plans[]` | 3 пакета: вход / основной (`rec:true`) / расширенный; `price` «от …», `time`, `items[]` |
| `assure` | `give` («что гарантируем») и `depends` («что зависит от исходников») |
| `more.items[]` | софт и консалтинг: `i` (код), `t`, `d` |
| `next` | `title`, `lead`, `btn`: один следующий шаг |
| `viewer` | 3D-блок: `models[]` (`label`, `src` .glb, `poster`, `orbit`), `ratio`, `caption`. Нет файла — показывается заглушка. Добавить `'viewer'` в `blocks` |
| `flag` | `false` прячет плашку «демо-шаблон» (если ключ `demo` занят кадрами) |
| `toc`, `products`, `productsTitle` | подписи оглавления (`index`), карточки изделий (`halftone`) |

Изображения кладите рядом (например `assets/`) и указывайте путь относительно `index.html`. Отдавайте их в WebP, не в PNG: `tools/to_webp.sh for/<slug>/assets` сжимает рендеры в 40–100 раз без видимой потери, а PNG-оригиналы держите вне репозитория (папка `./` целиком уходит на деплой). Для `halftone` и обложки `editorial` лучше светлый или белый фон: он превращается в тон схемы.

## Что есть внутри

Анимации (только `transform`, `opacity`, `clip-path`): появление блоков по скроллу, заголовки по словам и буквам, счётчики чисел, прогресс-бар чтения, параллакс и clip-path раскрытие кадров, hover на строках списков и оглавления. Всё отключается при `prefers-reduced-motion`. На телефоне (до 760 px) появляется липкая кнопка CTA, она прячется на обложке и в финальном блоке. Переключатель RU/EN запоминается в `localStorage`.

## Чек-лист перед отправкой

- [ ] `demo:false`, нет упоминаний «Компании X», «демо-значение», «[дата]», «[N]».
- [ ] У каждого из 3 фактов есть источник: ссылка или документ и дата просмотра. Факта нет в открытых источниках, значит его нет в КП. Внутренних данных клиента мы не видели, и об этом сказано в тексте.
- [ ] «Задача их словами» сверена с публичными материалами; нигде не выдана за прямую цитату, если это не она.
- [ ] Сроки в шагах считаются от получения исходников. Цены «от», и они совпадают с актуальным прайсом.
- [ ] Бесплатный пробный кадр обещан только если исходник подходит (полная сборка в STEP, внутренние детали на месте). Иначе уберите из шагов и из `next.lead`.
- [ ] В демо стоят только условные модели с подписью «Демонстрация на условной модели»; чужих изделий и логотипов под видом наших работ нет.
- [ ] На обложке нет слова «ИИ»; консалтинг по ИИ только в блоке «Кроме визуала».
- [ ] Проверено в RU и EN, на 390 и 360 px нет горизонтального скролла, кнопки ≥ 44 px, консоль без ошибок.
- [ ] В `<head>` есть `<meta name="robots" content="noindex,nofollow">`, ссылка нигде не опубликована открыто.
- [ ] Ссылка CTA ведёт на бриф с `src=<slug>`.
