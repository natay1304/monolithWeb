01 Что такое скилл и зачем он нужен

Скилл (по-английски skill, «навык») — это папка с инструкцией для Claude Code. Внутри главный файл SKILL.md: в начале короткое описание «когда меня использовать», ниже — пошаговая инструкция. Claude Code держит в памяти только описание, а всю инструкцию открывает, когда задача подходит. Поэтому скиллов можно поставить много, и они не мешают друг другу.

Зачем это нужно: вы один раз записываете проверенный путь — например, как выложить сайт на Cloudflare через GitHub, — и дальше Claude Code ведёт по нему любого человека. Без скилла каждому пришлось бы писать длинный промпт и самому вспоминать, что и в каком порядке делать.

02 Что умеет этот скилл

Скилл называется third-brain-web и состоит из трёх блоков — это те же гайды, что лежат на этом сайте:

  • Написать сайт. Какие вопросы задать себе в начале, как разложить файлы, как сделать сайт удобным на телефоне, что проверить перед публикацией.
  • Выложить в интернет. Как отправить код на GitHub и опубликовать сайт на Cloudflare, чтобы он обновлялся сам.
  • Купить домен. Как выбрать имя, где купить (Cloudflare или Reg.ru), как привязать домен к сайту.

Скилл говорит с вами простыми словами, объясняет термины и ведёт по одному шагу, а не вываливает всё сразу. И у него есть жёсткие правила:

Чего скилл не делает

Не вводит данные банковской карты и не оплачивает покупки. Не создаёт аккаунты и не вводит пароли. Не принимает за вас решение о доступе Cloudflare к GitHub. Не просит присылать пароли и ключи. Не делает git push и не меняет настройки домена без вашего согласия. Всё это делаете вы сами, а скилл объясняет, куда нажать.

03 Как установить

Нужен сам Claude Code (приложение или версия для терминала). Дальше:

  1. Скачайте архив по кнопке «Скачать скилл (zip)» выше.
  2. Распакуйте его — получится папка third-brain-web.
  3. Положите папку в ~/.claude/skills/ — это папка скиллов Claude Code в вашем домашнем каталоге. На Windows это C:\Users\ВашеИмя\.claude\skills\. Если такой папки ещё нет, создайте её. Вложенность должна быть такой: .claude/skills/third-brain-web/SKILL.md.
  4. Перезапустите Claude Code. Новые скиллы он подхватывает при запуске.

Если удобнее через терминал, одна команда делает то же самое (архив лежит в «Загрузках»):

Команда для терминала (macOS / Linux) 
mkdir -p ~/.claude/skills && unzip ~/Downloads/third-brain-web.zip -d ~/.claude/skills/

Или попросите Claude Code сделать это за вас:

Промпт для нейронки — установить скилл 
Я скачала архив third-brain-web.zip в папку «Загрузки».
Распакуй его в ~/.claude/skills/ так, чтобы получился файл
~/.claude/skills/third-brain-web/SKILL.md, и проверь, что он на месте.
Ничего другого в этой папке не меняй.

Как проверить, что скилл встал. Перезапустите Claude Code и начните вводить / — в списке должен появиться third-brain-web. Или спросите: «Какие у тебя есть скиллы?».

Если хотите, чтобы скилл работал только в одном проекте, положите папку в .claude/skills/ внутри этого проекта.

04 Как пользоваться

Специально вызывать скилл не нужно: просто говорите Claude Code, что хотите сделать, и он сам подключит инструкцию. Примеры того, что можно написать:

  • «Помоги сделать простой сайт-визитку».
  • «Хочу выложить мой сайт в интернет через GitHub и Cloudflare».
  • «Помоги выбрать и купить домен для сайта».
  • «Я купила домен на Reg.ru, как привязать его к сайту на Cloudflare?»

Можно и вызвать скилл напрямую, набрав /third-brain-web.

Дальше Claude Code сначала задаст пару вопросов (есть ли уже код, есть ли аккаунты), а потом пойдёт по шагам. На каждом шаге он будет просить вас сказать, что вы видите на экране, — так вы не потеряетесь, даже если кнопки в Cloudflare уже переставили. Всё, что связано с деньгами и доступами, вы делаете сами.

05 Важно знать

  • Интерфейсы меняются. Названия кнопок в Cloudflare, GitHub и у регистраторов верны на конец сентября 2026. Если экран выглядит иначе, скилл попросит описать, что вы видите, и будет ориентироваться на это.
  • Цены и лимиты — ориентировочные. Перед покупкой домена сверьте цену на сайте регистратора.
  • Скилл только для статичных сайтов. Сайты с серверной частью (например, форма, которая сама шлёт письма) в него не входят.
  • Шаги Reg.ru и экраны покупки доменов в скилле описаны без живой проверки в панели. Реальные экраны Cloudflare для покупки домена сняты на скриншотах в гайде про домен.
  • Обновления. Скилл не обновляется сам. Если я его поправлю, скачайте архив заново и замените папку.

06 Частые вопросы

Это платно?
Сам скилл бесплатный. Платным может быть только домен и сам Claude Code, если у вас нет доступа.
Можно ли его править под себя?
Да, это обычные текстовые файлы: откройте SKILL.md и файлы в папке references в любом редакторе. Главное — не удалять строки между тремя дефисами в самом начале SKILL.md: по ним Claude Code узнаёт скилл.
Я новичок, мне это подойдёт?
Да, скилл как раз для тех, кто делает это впервые. Но если что-то непонятно, сначала прочитайте соответствующий гайд на сайте: там те же шаги со скриншотами.
Где посмотреть, что внутри?
Главный файл можно открыть прямо в браузере: SKILL.md.
