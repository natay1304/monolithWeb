## Решения, которые не переоткрывать

1. Два бренда / два сайта, без перекрёстных ссылок.
2. Промышленный сайт — основная ставка.
3. В H1 не продавать «ИИ» — точность, скорость, покрытие каталога.
4. CAD/3D = источник правды; ИИ только для среды и света.
5. Демо-кейсы на открытых моделях, подписанные честно.
6. Не запускать платную рекламу, пока нет кейса и заявка не доходит.
7. На телефоне не убивать сцену целиком: облегчённое поле колонн + матовые панели под текстом.
