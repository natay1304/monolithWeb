# Оффер сайта №2 — промышленный B2B

Выписка из `Anastasia_Malutina_AI_Content_2026.md` (части 8–9) и брифинга 9 сентября 2026.
Полный бизнес-документ с рынком, сайтом №1 и прайсом на рабочем столе не копируется сюда.

Решения ниже **не переоткрывать**. Рабочий план правок: [../PLAN.md](../PLAN.md).

## Решения, которые уже приняты

1. **Два отдельных сайта**, разные бренды, домены и почты. Никаких перекрёстных ссылок. Аудитории подают противоположные сигналы доверия.
2. **Промышленный сайт — основная ставка.** Генеративный «инстаграмный» — быстрые деньги и тренажёр продаж.
3. **В H1 не продавать «ИИ».** Для инженера это «он придумает мой станок». Продавать точность, скорость и покрытие каталога. Технологию раскрывать отдельно.
4. **Пайплайн:** CAD/3D как источник правды, ИИ только для окружения, света и финиша. Чистая генерация даёт дрейф геометрии.
5. **Это и есть преимущество:** 3D-студии точны, но медленны; AI-креаторы быстры, но плывут в болтах. Держать оба конца пайплайна умеют единицы.
6. **Демо-кейсы на открытых моделях**, подписанные честно. Плюс развернуть Sofa — тот же класс задач, что инструмент.
7. **Платную рекламу не запускать**, пока нет кейса и форма не приносит заявки. Окупается при чеке от 1 000 $ и только на конвертящем сайте.
8. **Не склеивать бренды.** Не публиковать выдуманные логотипы клиентов.

## 8.1. Главное правило: не продавать ИИ

Плохо: «ИИ-визуализация для промышленности».
Хорошо: «Фотореалистичные изображения продукта из ваших CAD-данных. Каталог целиком, за дни, без съёмки».

Технологию раскрыть на странице «Как это устроено»: геометрия из модели не меняется; ИИ — среда, свет, постобработка.

## 8.2. Почему здесь преимущество

| Лагерь | Сила | Слабость |
|---|---|---|
| Классические 3D-студии | Точность | 4–10 недель, дорого, правка спецификации = заново |
| AI-креаторы | Скорость | Дрейф геометрии, болты «плывут», надписи — абракадабра |

Рабочий пайплайн 2026: точная модель + ИИ для среды. Навыки, которые это закрывают: Unity URP/HDRP, Trellis / image-to-3D, Three.js, Vuforia/AR, автоматизация батчей, QA с приёмочными критериями.

## 8.3. Что нужно клиентам

- **Базовый визуал** — герой на белом, 6–12 ракурсов, узлы, цвета и комплектации
- **Контекст** — площадка, цех, мастерская; день / рабочий свет; масштаб с человеком
- **Техграфика** — взрыв-схемы, разрезы, монтаж
- **Динамика** — 360°, короткие ролики функций, принцип работы
- **Интерактив** — просмотрщик на странице товара, конфигуратор, AR в цеху
- **Данные** — пакет на артикул для дилеров, обновление при смене спецификации

## 8.4. Боли для текстов

- Каталог на 500 позиций, нормальные фото у 150
- Продукт через два месяца, каталог на выставку нужен сейчас
- Оборудование нельзя привезти в студию
- Поменяли спецификацию — переснимать всё
- Покупатель решает до звонка менеджеру

## 8.5. Целевая структура URL (этап D, не сейчас)

```
/                          оффер, отрасли, работы, экономика, CTA
/industries/...            строительство, инструмент, оборудование, материалы
/services/...              каталог, контекст, техграфика, интерактив, видео
/technology                модель как источник правды
/work                      кейсы
/pricing                   пакеты «от»
/contact                   форма
```

Сейчас сайт — статический hash-роутер (`#/main`, `#/lab`, `#/capabilities`, `#/brief`). Отдельные URL — после проверки оффера, не ради «правильного стека».

## 8.6. Главная

1. Результат, не миссия. CTA «тестовый рендер» над сгибом.
2. Экономика: сравнение съёмка / 3D-студия / модель+среда.
3. Точность в трёх предложениях.
4. Отрасли карточками.
5. Кейсы — даже учебные, с честной подписью.
6. Живой 3D-виджет изделия (ещё не сделан).
7. Процесс, сроки, пробный рендер как вход.

## 8.7. Тон

Как инженер для инженера: цифры, сроки, форматы (STEP, IGES, STL, OBJ, FBX, DXF). Без превосходных степеней, эмодзи и «вау». Сдержанность = компетентность.

## 8.8. Нет промышленных кейсов

Взять 3–4 модели с GrabCAD / Sketchfab / Thangs. Полный пакет: герой, контекст, взрыв-схема, 360°. Подпись: «демонстрационный проект на открытой модели». Развернуть Sofa. Не намекать на несуществующих клиентов.
