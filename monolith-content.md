## 02 // LAB

Пайплайн остаётся 4-этапным, формулировки расширяются с CAD-центричных на универсальные:

- `01 INGEST` — принимаем любые исходники: CAD/BIM, генпланы, каталоги, брендбук, фото с площадки или прилавка.
- `02 RECONSTRUCT` — собираем цифровую сцену: объект, продукт или пространство в точной геометрии.
- `03 SIMULATE` — свет, погода, сезон, среда, люди и техника в кадре. Здесь «скучное» становится кинематографичным.
- `04 RENDER` — финальные форматы: 4K-видео, стиллы, вертикали, лендинг, макеты для печати.

### FAQ (аккордеон, моно-индексы Q_01…)

- `Q_01 // Мой продукт скучный: арматура, комбикорм, сухие смеси. Что вы с ним сделаете?`
  Скучных продуктов нет, есть продукты, которые никогда не снимали правильно. Арматуру можно показать как графику из стали, комбикорм — как поток золотого зерна в утреннем свете. Мы делаем с «немодными» продуктами то, что реклама десятилетиями делала с автомобилями и парфюмом: свет, ракурс, среда, масштаб.

- `Q_02 // Насколько картинка будет соответствовать реальному объекту?`
  Если на входе есть документация (CAD/BIM, генплан, чертежи), геометрия и компоновка соответствуют ей: это визуализация вашего проекта, а не «фантазия нейросети по мотивам». Атмосфера — свет, погода, стаффаж — художественный слой поверх точной основы, и он всегда согласуется с вами.

- `Q_03 // Что с конфиденциальностью? У нас чертежи под NDA.`
  NDA — до передачи любых материалов, по умолчанию. Исходники хранятся в изолированном контуре проекта, не используются для обучения моделей и удаляются по завершении, если не договорились об архиве для будущих обновлений.

- `Q_04 // Проект изменится через полгода. Ролик придётся выбрасывать?`
  Нет. Сцена проекта сохраняется, и обновление — это инкремент, а не производство с нуля: заменяем изменившиеся корпуса, обновляем фасады, перегенерируем затронутые кадры. Обычно это 15–30% стоимости исходного проекта.

- `Q_05 // У меня только фотографии с телефона. Этого хватит?`
  В большинстве случаев — да. Для витрины, торгового зала или продукта достаточно 5–10 фотографий при обычном освещении. Мы восстановим пространство и покажем варианты оформления фотореалистично. Чем больше исходников, тем точнее результат, но порог входа — минимальный.

- `Q_06 // Чем вы отличаетесь от фрилансера с нейросетью?`
  Тем же, чем типография отличается от принтера. Модели доступны всем; результат определяют пайплайн, художественная постановка, инженерная точность и ответственность за сроки. Мы отдаём не «картинки из чата», а согласованный продакшн: выверенную геометрию, единый стиль всех материалов и файлы, готовые к печати, эфиру и тендеру.

## 03 // ARCHIVE → CAPABILITIES

Реальных кейсов пока нет. Страница на старте — **витрина возможностей** ИИ-генерации для бизнеса:
никаких вымышленных клиентов, цитат и «выполненных проектов». Карточки описывают, что студия
умеет делать, на каких исходниках и с каким результатом. Реальные кейсы добавляются позже
без переделки страницы (архитектура ниже).

**Заголовок страницы:** `03 // CAPABILITIES` · RU: `ВОЗМОЖНОСТИ`
Плашка: `CAPABILITY INDEX — CASE STUDIES COMING SOON` / «Индекс возможностей — кейсы появятся по мере выполнения проектов».

### Архитектура под будущие кейсы (в content.js)

```js
// Один массив, один рендерер карточек. kind определяет подачу.
ARCHIVE_ITEMS = [
  { kind: 'capability', id, index, title: {en, ru}, sector: {en, ru},
    input: {en, ru},          // что нужно на входе
    output: {en, ru},         // что получается на выходе
    metrics: [{label: {en, ru}, value}],   // питают hover-гистограмму колонн
    media: { type: 'placeholder' | 'image' | 'video', src },
    description: {en, ru} },
  // будущий реальный кейс — та же схема + поля клиента:
  // { kind: 'case', ..., client, location, year, quote: {text, author} }
]
```

- Рендерер поддерживает оба `kind` сразу: у `capability` вместо `location/year` выводится строка `INPUT → OUTPUT`; у `case` — клиент, год, цитата.
- Появился первый реальный кейс → он добавляется в массив, страница автоматически показывает секцию `CASES` над `CAPABILITIES`, плашка «coming soon» скрывается. Ни одна строка движка не меняется.
- Фильтр-строка собирается из уникальных `sector` элементов массива — работает и для возможностей, и для кейсов.
- `media.placeholder` — процедурная заглушка в стиле сетки (как в плане); у возможностей может остаться навсегда, у кейсов заменяется на реальные файлы в `assets/cases/`.

### Карточки возможностей (6 шт.)

**CAP_01 — ОБЪЕКТ ДО ПОСТРОЙКИ** · OBJECTS
Синематик здания, завода, терминала или района — до первого котлована. Проектная документация превращается в кино: объект показан построенным, в среде, в любое время суток и сезон.
`INPUT:` CAD/BIM, генплан, фасадные решения → `OUTPUT:` синематик 4K 30–120 сек, стиллы, ракурсы для тендера
Метрики: `Разрешение, K — 4` · `Ракурсов за проект — 24` · `Недель — 4–6`

**CAP_02 — ПРОИЗВОДСТВО БЕЗ СЪЁМКИ** · PRODUCTION
Цеха, линии и процессы — без остановки производства, допусков и съёмочных групп. Действующее предприятие показано так, как его не снять физически: сквозные пролёты, разрезы, макросъёмка процессов.
`INPUT:` фото цехов, паспорта оборудования, чертежи линий → `OUTPUT:` видео производства, стиллы для сайта и презентаций
Метрики: `Дней на площадке — 0` · `Сцен — 12` · `Недель — 3–4`

**CAP_03 — ПРОДУКТ БЕЗ ФОТОСТУДИИ** · PRODUCT
Предметная съёмка индустриального продукта — из каталога и 3D-модели. Оборудование, инструмент, материалы — в постановочном свете и среде применения, как снимают часы и автомобили.
`INPUT:` каталог, STEP/3D-модель или 5–10 фото → `OUTPUT:` предметные кадры, среда применения, серия для каталога
Метрики: `Кадров на SKU — 8` · `SKU за проект — 40` · `Недели — 2`

**CAP_04 — ЛЕНДИНГ-ПРЕЗЕНТАЦИЯ** · DIGITAL
Одностраничный сайт проекта или продукта: сгенерированный визуал, структура, тексты. Для запуска продаж, тендера или инвест-питча — когда нужен не «сайт вообще», а страница одного решения.
`INPUT:` материалы проекта, брендбук (если есть) → `OUTPUT:` готовый к публикации лендинг + исходники визуала
Метрики: `Экранов — 8` · `Языков — 2` · `Недели — 1–2`

**CAP_05 — ВИТРИНЫ И ПРОСТРАНСТВА** · SPACES
Оформление витрин, шоурумов, торговых залов и выставочных стендов — сначала фотореалистичная визуализация вариантов, потом макеты для производства.
`INPUT:` фото помещения, логотип, ассортимент → `OUTPUT:` варианты оформления, макеты для печати и производства
Метрики: `Вариантов концепции — 3` · `Точек сети — без ограничений` · `Недели — 1–2`
